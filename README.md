# カカシ工房 — 農家爆受けのカカシを作れ！（Unity版）

▶ **ブラウザで遊ぶ（iPhone Safari対応）**：https://titan11111.github.io/108KAKASHI2/

Web版（Three.js）を参考に、Unityで**ゼロから**組み直したプロジェクトです。
Prefab・外部アセット・画像は一切使わず、すべてC#のコードでプリミティブから3Dを生成します。

## 遊び方（Unityで開く）

1. Unity Hub →「追加」→ この `KakashiUnity` フォルダを選ぶ（Unity 6 系を推奨）
2. 開くと自動で `Assets/Scenes/Main.unity` が作られる（作られない時はメニュー **Kakashi → シーンを作る・設定する**）
3. ▶ を押す

この作業でローカルEditorが準備されている場合は、`Tools/play.sh` でも開けます（初回は自動動作確認を実施し、工房画面を再生したままにします）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Scripts/Data.cs` | 素材・パーツ・農家3人・かかし文化・採点・動物の反応ルール |
| `Scripts/Geo.cs` | プリミティブ／円錐メッシュ／素材（マテリアル）／風の揺れ・風車回転 |
| `Scripts/Scarecrow.cs` | 選んだパーツから3Dカカシを組み立てる（9部位） |
| `Scripts/Env.cs` | 夕暮れの畑・農家・カラス／猿／猪／鹿・カメラ・入力 |
| `Scripts/UIKit.cs` | コードだけでuGUIを組む道具 |
| `Scripts/GameController.cs` | 進行：つくる → さす（襲来テスト）→ 評価 → 結果 |
| `Editor/KakashiSetup.cs` | シーン自動生成・WebGLビルドメニュー |

## 見た目の強化（v2）

- `Tex.cs`：画像なしで質感を生成（木目・わら・綿・草・毛・土・織り＋藍染の絣／赤水玉／金襴／つぎはぎ柄）。タイル可能
- `Geo.Mat` が色から質感を自動判定（`Geo.Force`）。生成中だけ有効で、終わると元に戻る
- 夕焼けスカイボックス、逆光の太陽＋手前の補助光、風に揺れる作物（約240株）、小屋・木・藁山・小石
- 動物：脚の歩行、しっぽ、鹿の耳、カラスの尾羽・羽ばたき
- カカシ：垂れ布・肩布が風でひらひら揺れる
- Skybox/Procedural と Standard は、メニュー **Kakashi → シーンを作る・設定する** で「Always Included Shaders」に登録されます

## 注意（必読）

- 実行確認の結果は `Verification/play-report.txt` に保存します。ファイル未生成・Passed: False の状態では、動作確認済みではありません。
- 日本語フォント：iOS／Mac／Windows ではOSフォントを使います。**WebGL では必ず** 日本語フォント（例：Noto Sans JP）を
  `Assets/Resources/JpFont.otf` として置いてください（コードが自動で読み込みます）。
- 「形を整える」から9部位の位置・傾き・ひねり・大きさを調整できます。部位のタップ選択・ドラッグ移動・部位リセットに対応し、偏った形は安定度に反映します。
- 縦画面では下部パネル、横画面では右側パネルを表示。UIはsafe area内に配置します。
- クリック・衝撃・カラス・風の効果音はコードで生成します。画面左上の音ボタンで切り替えます。
- 動作確認メニュー：**Kakashi → 再生して動作確認**。形状調整→襲来→農家3人→結果→工房に戻るまでを自動操作し、`Verification/play-report.txt`へ実測結果を保存します。
- 動物の襲来結果は、Web版の続き部分が未確認のため、同じ考え方で作り直した判定ルール（`Data.Simulate`）です。
